# Sill

A persistent memory system for AI agents. Postgres + pgvector + Apache AGE
behind an MCP server, with a Claude Code / Codex plugin that wires
spontaneous recall, attribution checks, response-pattern detection, and a
small set of other discipline hooks.

Extracted from the agi-memory research project. See `docs/` for setup,
concepts, and how to extend with your own hooks.
